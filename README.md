# Páginas legales de Statlyra

Política de privacidad y condiciones del servicio de los juegos de Statlyra.
Se publican en GitHub Pages porque Google Play y la pantalla de consentimiento
de OAuth las exigen en una URL pública.

Este repositorio es público a propósito: solo contiene documentos que deben
serlo. El código de los juegos vive en repositorios aparte.

- [Política de Privacidad](privacidad.html)
- [Condiciones del Servicio](terminos.html)
